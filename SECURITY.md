# Security

If you find a security problem, please report it privately through GitHub:
open the **Security** tab of this repository and choose **Report a vulnerability**.

Please do not open a public issue with the details. If the Security tab does not offer that option, open an issue that says only "security", and I will contact you.

This is a personal project. I will read every report, but I cannot promise a fix or a reply time.

Known open issues are listed under "Known limits" in the [README](README.md).
